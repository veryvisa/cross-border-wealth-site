避免 建议

  • 是否出现个案意见？

转介与自检知识卡

系列定位与讲师红线

1.1 一句话定位 帮助跨境家庭看清三件事——谁的身份（Who）→ 资产在哪国（Where）→ 需要什么文件与申报（What to file）——并知道何时该请专业人士；本系列不替代专业人士。

1.2 听众三线

线 画像 核心关切
A 线 父母为加拿大税务居民（BC 为主），子女在美国读书或工作 资金合规进入美国；美股与美国房产的遗产税；加拿大死亡视同处置
B 线 父母在中国大陆，子女在美或在加 汇出额度与用途；赠与文件；继承文件认证
C 线 子女本人：F-1/J-1 在读 → OPT → H-1B → 绿卡，或已是美国税务居民 居民起算日；8843；3520；PFIC 与账户申报；婚姻风险

1.3 学习成果（全系列结束后，学员能够）

  1. 区分四种“居民”（移民身份、所得税居民、遗产赠与税住所、条约居民），并为自家建档；
  2. 判断一笔跨境资金或资产是否触发申报，并理解“申报≠缴税”；
  3. 用公式而非口号，估算美国遗产税暴露（比例抵免）与加拿大死亡视同处置税；
  4. 列出一次跨国继承要跑的国家、文件与认证；
  5. 建立家庭年度申报日历与专业人士转介清单。

1.4 每讲统一收尾：三问清单 谁的身份？什么资产在哪国？需要什么文件或申报？

1.5 讲师红线

  • 只讲选项、条件与风险；不推荐具体产品、结构或机构；不出个案意见。
  • 不讲规避申报、隐匿资产、拆分额度、欺诈性转让的做法；涉及时只作风险提示。
  • 数字必须条件化，并说明来源与算法；没有官方来源的说法不进课件。
  • 保险、投资、移民、税务内容，按讲师本人的牌照范围与监管机构的宣传规定审阅全部讲稿与文案。
